# Release Notes

## Project overview to date - 2026-05-28
- WebPeezy is a desktop app for converting images to WebP format.
- The app supports drag-and-drop imports, file browsing, and batch conversion of multiple images.
- Users can save custom conversion presets with configurable image dimensions and quality settings.
- The interface shows converted-image previews and file size savings, and includes a bulk export flow for downloading all converted files.
- The app is packaged with Tauri as a desktop application under the `WebPeezy` product name.
